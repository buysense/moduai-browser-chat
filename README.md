# 모두의AI 브라우저 챗 데모

GitHub Pages에서 바로 실행되는 브라우저 로컬 AI 챗 실험입니다.

## 목표

- 블로그 방문자가 별도 앱 설치 없이 웹페이지에서 AI 챗을 체험합니다.
- 서버 API를 호출하지 않고 WebLLM으로 브라우저 안에서 모델을 실행합니다.
- 무의미한 블로그 트래픽이 서버 모델 비용으로 이어지지 않게 합니다.

## 기술

- 정적 HTML/CSS/JavaScript
- WebLLM CDN import
- GitHub Pages 배포

## 제약

- WebGPU 지원 브라우저가 필요합니다.
- 첫 실행 시 모델 다운로드와 초기화 시간이 걸립니다.
- 모바일이나 구형 브라우저에서는 실행되지 않을 수 있습니다.
- 답변 품질은 고성능 서버 모델과 다를 수 있습니다.

## 로컬 확인

정적 파일 서버를 열어 확인합니다.

```powershell
python -m http.server 8080
```

그 다음 `http://localhost:8080`으로 접속합니다.
